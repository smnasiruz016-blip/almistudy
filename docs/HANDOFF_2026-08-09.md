## THE DEDUPE PIPELINE, AS IT NOW STANDS

This is the day's main engineering output and it should not be re-derived from scratch.
`_merge_additions.py` dedupes on a byte-identical `(country.slug, slug)` key. Everything
below is what that key cannot see. Each detector is blind to what the others catch.

| # | detector | catches | example |
|---|---|---|---|
| 1 | full-slug token similarity ≥0.8 | acronym-suffixed, stopword-dropped | `…-umsa` vs live plain |
| 2 | normalised **name** ≥0.6, per country | **language pairs**, eponym added | `universidad-de-buenos-aires` vs live `university-of-buenos-aires` |
| 3 | parenthetical **acronym** exact | acronym is the only shared token | `(UNESP)` linking two names with zero words in common |
| 4 | live name as **substring** of batch name | **renamed institutions** | live `tishreen-university` vs batch `latakia-university` |
| — | **shared acronym + same city** | the single highest-yield rule | `University of El Salvador (UES)` vs `Universidad de El Salvador` |

**Past ~200 rows a batch needs an adjudicator, not an eyeball.** Classify every candidate
into CERTAIN / REVIEW and read only the residue. On the 639-row J–O batch that was 123
certain, 28 to review, of which 25 were also duplicates.

⚠️ **Detector 4 must never auto-drop.** Direction decides: a qualifier BEHIND a name is
usually the same institution (`Ismail Qemali University` → `…University of Vlora`), a
qualifier IN FRONT usually is not (`Metropolitan University of Tirana` ≠
`University of Tirana`). It produced one false drop, caught on review.

⚠️ **A wrong partner and a wrong verdict look identical in the log.** The adjudicator
records the best-scoring live row; in J–O it matched UPAN against the wrong Salvadoran
university yet the drop was still correct, because a different live row was its true
twin. Check the partner before trusting the reason.

## RULES THAT COST SOMETHING TO LEARN

**Country identity first, before any per-country metric.** The Turkey batch declared
`country.slug "turkey"` while live is `turkiye`. Merging as-is would have created a
second Türkiye country page in the wrong region plus 26 shadowed `/university/[slug]`
pages. Worse, while the key was wrong the per-country duplicate scan was *blind* —
fixing the identity exposed two more duplicates nothing else could see.

**An already-merged batch file is not a safe no-op.** Corrections live in the prepared
copies, never upstream. Re-running Batch A's raw files would have re-injected 206 bad
rows, 198 of them the phantom Turkey country. `--dry-run` every file before a re-run.

**A directory glob is not a work-list.** Seven Europe files landed in the data folder
mid-session and the first J–O prep silently swallowed all 216 rows. Take the filename
list from the brief and assert its length.

**Merge once, not once per file.** 41 sequential invocations each re-read and re-wrote
the 17 MB dataset; the loop timed out two-thirds through and left a partial merge. One
pass replicating the script's semantics — same order, same sequential ids, same
accumulating key — is minutes instead of hours.

**Never normalise a URL scheme on appearance; curl it.** Same symptom, four different
right answers: China's MOE `https` **302s back to http** (http was correct) · Côte
d'Ivoire, Tunisia and Mali `http` **301 to https** (http was the defect) · Syria's `http`
**does not answer at all** while https returns 200 · Venezuela's registry answers on
**neither** (left alone, could-not-prove). A **403 is a server answering** — Bahrain's
MoE, Brazil's e-MEC and Ukraine's MON all bot-block and are live. A **404 is dead** —
Bahrain's `/hec/` path was replaced.

## TWO DEFECTS FOUND IN OUR OWN LIVE DATA

**`UNI_5227` — a `placeholder` row was serving a real page.** Slug `placeholder`, notes
"IGNORE - placeholder", city null, subjects `[]`. It came in the Turkey batch and shipped.
The pre-flight *had* reported it as `null_city=1 zero_subjects=1` and that was read as a
tolerated thin row — it was **one row that was both**. That conjunction is the signal.
Now deactivated via `publishable: false`.

Fixing it exposed the larger problem: **the `publishable` flag was inert in the Next.js
app.** The satellite generator honoured it; `lib/page-relations.ts` read the array
verbatim, so an unpublishable row still got a page, a sitemap entry and a country
listing. Now filtered at that single source, which `lib/static-index.ts` derives from.

**Two Syrian universities carried names abolished by decree.** Syria renamed its
Baathist-named institutions in 2025 (SANA decrees 99 and 100). `UNI_1470` and `UNI_1471`
now read Latakia University and Homs University with the former names retained after an
em dash. **Slugs untouched**, so no URL changed and no redirect is needed.

**`isr-policy.ts` `approxPages` was stale for two commits.** The edit was bundled into a
backgrounded compound command; when that run was abandoned the data file was reverted and
isr-policy was not, so the follow-up edit asserted on a value that no longer existed and
its failure was never read. Two commit messages overstate what landed. The gate could not
catch it because it only compares `approxPages` to the 50,000 ceiling — **it should assert
against `universitySubjectPairs()` instead of trusting the number.** Not done; it is the
single highest-value gate improvement outstanding.

## STANDING NOTES

- **Spend:** the on-demand budget and Pause Projects were what took 12 subdomains down on
  2026-08-08. All 13 are up. Each deploy re-arms ~34,000 ISR writes, so **docs-only
  commits should ride along with the next data merge rather than deploy alone.**
- `_merge_additions.py` takes **two** arguments (live path, additions path), one file per
  call, and lives in the OneDrive data folder — not in the repo.
- `almistudy_generate_v2.py` needs the dataset path explicitly, or it silently falls back
  to `sample_universities.json`.
- Founding years are now phrased "reportedly founded YEAR (per public sources)" — **0
  hard-asserted years** across the last six batches. `established` remains null on all
  7,609 rows, so the year exists only as prose and no gate validates it.

  city and no subjects, and says so honestly. It is a real CONEAUPA-recognised
